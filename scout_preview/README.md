# Scout Match Report Preview

This folder contains a high-fidelity **Live Preview** of the final Scout Match Report format.

### Files:
- `scout_match_report_preview.html`: The interactive report.

### How to see the Visual Result:
1. Open `scout_match_report_preview.html` in your browser (Chrome/Edge recommended).
2. To see the **Video Player** in action:
   - Copy your `veo_match_video.mp4` file into this `scout_preview` folder.
   - Rename it to `veo_match_video.mp4` (if it isn't already).
3. The report will automatically find the video and allow you to click on "Goal" or "Save" buttons to jump to those moments in the match!

> [!NOTE]
> This is a preview using sample data to show you the UI design and features while the Lightning AI finishes the full analysis.
